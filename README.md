# project-trays

Stackable project trays with integrated USB hub mounting.

## Current draft

- **v1 USB hub tray** — 9" × 6" × 3", open front with 1/4" ledge, Anker USB-C hub bay on the back wall.
- Model: [`tray_usb_hub_v1.scad`](tray_usb_hub_v1.scad) (OpenSCAD)
- Notes: [`docs/tray_usb_hub_v1.md`](docs/tray_usb_hub_v1.md)
- Renders: [`renders/v1/`](renders/v1/)
- STL: [`export/tray_usb_hub_v1.stl`](export/tray_usb_hub_v1.stl)

## Build

```bash
# Preview / edit in OpenSCAD GUI, or:
"C:\Program Files\OpenSCAD\openscad.exe" -o export/tray_usb_hub_v1.stl --render tray_usb_hub_v1.scad
```
